单链表：创建、遍历与插入(New)

把一个个节点连起来，再顺着 next 走到最后。

昨天的代码相对简陋，缺少了头部插入的情况，逻辑上也有所错误

这是新的一版

struct Node{
    int data;
    struct Node* next;
};
struct Node* InsertHead(int value,struct Node* head){
    if(head == NULL){
        printf("链表不存在，创造新链表\n");
    }
    struct Node* NewNode = malloc(sizeof(struct Node));
    NewNode -> data = value;
    NewNode -> next = head;
    head = NewNode;
    return head;
}

struct Node* InsertTail(int value,struct Node* head){
    struct Node* NewNode = malloc(sizeof(struct Node));
    NewNode -> data = value;
    NewNode -> next = NULL;
    if(head == NULL){
        printf("链表不存在，创造新链表\n");
        head = NewNode;
        return head;
    }
    struct Node* traveser = head;
    while(traveser->next != NULL){
        traveser = traveser -> next;
    }

    traveser -> next = NewNode;
    return head;
}

struct Node* InsertAfter(int value,struct Node* prev){
    if(prev == NULL){
        printf("前驱链表不能为空\n");
        return NULL;
    }
    struct Node* NewNode = malloc(sizeof(struct Node));
    NewNode -> data = value;
    NewNode -> next = NULL;
    NewNode -> next = prev -> next;
    prev -> next = NewNode;
    return NewNode;
}

void LinkPrint(struct Node* head){
    struct Node* traveser = head;
    int count = 0;
    if(traveser == NULL){
        printf("链表不存在\n");
        return;
    }
    while(traveser != NULL){
        printf("%d ",traveser -> data);
        traveser = traveser -> next;
        count++;
    }
    printf("一共有%d个链表\n",count);
    return;
}

int main(){
    struct Node* head = InsertHead(10,NULL);
    InsertTail(20,head);
    InsertAfter(50,head);
    LinkPrint(head);
    return 0;
}

分别为3个函数的测试使用

想到了插入时的left与right指针其实没有必要

理论上只需要left指针即可


        NewNode->next = prev->next;
        prev->next = NewNode;

其中的prev指针本质上即为left,right完全可以通过left->next得出

头部插入，尾部插入，以及中间的插入

头部的插入与其他两者不同，需要单独操作，并且产生并返回新的head指针

尾部插入实际上也是中间插入的一种，不过因为位置固定只需遍历到尾部，所以相对简单

中间的插入需要提供prev指针

单链表：删除

相对于插入，链表节点的删除比较简单，非头部节点只使用一个变量暂时储存该节点的指针，通过prev->next = prev->next->next与后面的节点链接

最后再free函数释放即可

头部节点，令head = head->next赋值后释放，最后返回新的head
