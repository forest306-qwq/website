单链表：创建、遍历与插入

把一个个节点连起来，再顺着 next 走到最后。

初步接触链表，通过指针完成各结构体的连接

对我而言，这是一个比较新奇的事物，也是我在学习了指针相关知识后的一次应用

此外，学习链表之前还需要掌握结构体和动态内存的相关知识

结构体学习了大致的使用方式，动态内存才学会malloc和calloc(我甚至连free都不会。。)

  • 用 struct Node 把数据和下一个节点的指针放在一起。
  • 用 head 记住链表起点，用 tail 记住末尾节点。
  • 用尾插法添加节点，沿着 next 遍历整条链表。
  • 使用完毕后释放节点，避免分配的内存一直保留。

完整代码

#include <stdio.h>
#include <stdlib.h>
struct Node{
    int data;
    struct Node* next;
};

struct Node* Node_create(int n){
    struct Node* head = (struct Node*)malloc(sizeof(struct Node));
    head->data = 1;
    head->next = NULL;
    struct Node* tail = head;
    for(int i = 2;i <= n;i++)
    {
        struct Node* newNode = (struct Node*)malloc(sizeof(struct Node));
        newNode->data = i;
        newNode->next = NULL;
        tail->next = newNode;
        tail = newNode;
    }
    return head;
}

void Node_insert(int position,int value,struct Node* head){
    struct Node* traverse = head;
    int count = 0;
    struct Node* left_pointer = NULL;
    struct Node* right_pointer = NULL;
    

    while(traverse != NULL)
    {
        traverse = traverse->next;
        count++;
        if(count == position - 2)
        left_pointer = traverse;
        if(count == position - 1)
        right_pointer = traverse;
    }

    struct Node* newNode = (struct Node*)malloc(sizeof(struct Node));
    newNode->data = value;
    newNode->next = right_pointer;
    left_pointer->next = newNode;
}
struct Node* traverse(struct Node* head){
    printf("链表内容:");
    struct Node* traverse_pointer = head;
    while(traverse_pointer != NULL){
        printf("%d ",traverse_pointer->data);
        traverse_pointer = traverse_pointer->next;
    }
    return traverse_pointer;
} 


int main(void){
    struct Node* head = Node_create(6);
    Node_insert(4,5,head);
    traverse(head);
    return 0;
}

运行结果

1 2 3 5 4 5 6

其中positon = 4的位置为插入结果，value = 5

创建链表的尾插法里最关键的两行

已有尾节点时，先把新节点接到尾部，再更新尾指针：

tail->next = newNode;
tail = newNode;

第一行改变的是节点之间的连接，第二行改变的是 tail 指向的位置。如果写成 newNode = tail，只是让局部变量指向旧尾节点，尾指针并没有推进。

链表为空时还没有尾节点，所以第一个节点需要单独赋给 head，之后再按同样的方式更新 tail。

遍历与内存插入

遍历时使用单独的 traverse_pointer 向后移动，保留原来的 head。遍历函数只负责打印，不需要返回走到末尾后的空指针,可以使用const修饰，说明其不会改变内容

插入时使用了指针left_positon和right_positon，两者可以把新插入的结构体串起来，达到插入的效果

此外，插入代码存在缺陷，只能插入position>=2的位置，这是一个后续的修改方向
